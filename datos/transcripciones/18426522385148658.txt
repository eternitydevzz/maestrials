Este repo de Github parece ilegal porque reúne miles de APIs públicas y en un solo lugar para que las uses hoy mismo desde tu casa. Se llama public APIs y ahí puedes encontrar datos de clima, películas, criptomonedas, noticias, deportes, finanzas e incluso información de la NASA. Entras, eliges la categoría que necesita y encuentras distintas opciones que puedes conectar a tus proyectos. Y esto se vuelve mucho más interesante cuando lo juntas con IA. Puedes crear sistemas que usen información real para responder preguntas, preparar réportes o acercarás automáticamente. Eso te permite construir relaciones para negocios en Estados Unidos sin tener que crear toda esa información desde cero y cobrar por resolverles un problema concreto. Si quieres el repo con todas estas APIs públicas para empezar a crear tu propio sistema, comenta API y te lo manda.
