Cloud Code ya puede editar vídeo y no solo cosas simples como subtítulos y cortes, sino ediciones completas de nivel profesional. DaVinci Resolve, que es un editor de vídeo gratuito a la altura de Premiere Pro, acaba de lanzar un servidor NCP oficial, así que ahora puedes conectarlo directamente a Cloud Code o Codes y controlar toda tu línea de tiempo, literalmente teniendo una sola conversación. Con esto puedes hacer corrección de color automática de tu material, montar motion graphics, crear cortes multicámara, añadir efectos de sonida e incluso ajustar tu propia música para que encajes perfecto con las ediciones. Además, si necesitas un clip de B-roll en medio, puedes hacer que Cloud los genere y soltar lo directo en la línea de tiempo. Si quieres todo el setas para montarlo para ti, solamente comenta vídeo aquí abajo en los comentarios y te mando el link directo.
