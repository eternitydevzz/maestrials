La gente sigue pagando Cloud Code cuando ahora puedas usar algo casi igual de potente y completamente gratis. Hasta ahora, programar con ella tenía un costumanso al fijo y no había otra alternativa. Pero alguien en Github construyó una herramienta que engaña a Cloud Code, haciéndole querer que habla con la versión oficial de Anthropic. Por detrás usa modelos que no cuestan nada y rinden entre el 80 y el 90% de lo que Cloud hace realmente. Más de 20.000 personas ya lo descubrieron y configurarlo toma en menas de 5 minutos. Para usarlos, simplemente entras al repositorio de Github y ejecuta dos comandos super simples. Eso instala un terminal compatible con Cloud Code sin pagar absolutamente nada. Luego lijas el proveedor que quiera. Envidia, para sacar claves sin costo, OpenRouter para modelos como DeepSync o GLM o Lama, si quieres correrlo directamente en tu computador es loca. Desde ahí tienes auto completado, agentes, flujos de trabajo y generación de código. Es decir, prácticamente igual que la versión oficial y el costo de programar con ella acaba de caer casi a 0.
