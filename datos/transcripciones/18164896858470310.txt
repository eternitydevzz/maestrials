Esta conexión hace que Cloud Code y Charged PD se repartan mi trabajo entre ellos. La idea es bastante simple. En vez de pedirle todo a Cloud Code, puede decir qué tarea hace él y cuál le pasa a Codex. Se conectan dentro del mismo proyecto usando una herramienta de OpenEye. Una idea puede encargarse de organizar el trabajo y la otra de construir alguna parte. Así no gastas todo tu uso disponible en un solo lugar y tampoco tienes que estar copiando instrucciones entre ventanas cada cinco minutos. Las dos pueden participar en el mismo proyecto con un trabajo distinto. Si quieres montar esta conexión entre Cloud Code y Codex para probarla en uno de tus proyectos, escribe Codex y te mando cómo configurar.
