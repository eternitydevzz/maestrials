Cloud Code acaba de hacer algo que da mucho miedo. Tomó control del computador y empezó a crear sistemas de AI solo, automáticamente. Y no solamente escribe código dentro de una carpeta, sino que navega por todo tu sistema y habla con otros programas directamente sin que tú le digas nada. Esta semana alguien le dio dos órdenes para probar hasta dónde podía llegar y lo que pasó después es lo que tiene a todo el mundo hablando. La primera orden fue, créame otro sistema de AI con Hermes dentro de Docker. Y Cloud Code lo montó solo. La segunda orden fue, entréanlo para que haga anuncios con Heisfield. Y adivina que lo entrenó, literalmente Cloud Code habló con Hermes, le instaló las herramientas los MCPs y lo dejó funcionando sin que nadie tocara nada más.
