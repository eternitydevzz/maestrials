Anthropid acaba de liberar una de las herramientas más potentes de Cloud y cualquiera puede usarlas desde hoy mismo. Anthropid publicó un repositorio oficial llamado Anthropid Skill, que permite que cualquier persona le enseñe a Cloud cómo hacer su proceso. Factura, reporte, documentos, flujos de trabajo repetitivos. Recuerda que una skill no es un mensaje normal para Cloud, es una carpeta con instrucciones completas que Cloud carga cuando la necesita. Dentro del repositorio oficial ya hay skills listas para crear documentos. Word, PDF, Excel y PowerPoints, todo con la intención de automatizar al máximo una empresa. Son las mismas skills que Cloud usa internamente para generar documentos. Para instalarlas, abres Cloud, escribes el comando, plugin, marketplace, add, Anthropid Skill, eliges las que quieres y listo. Desde ahí le pides a Cloud que use, por ejemplo, la skill de PDF y ejecuta todo el proceso solo siguiendo esas instrucciones. Si repite cualquier tarea hoy, puedes convertirla en una skill y que Cloud la haga por ti desde mañana. Saber que esto existe no te sirve de nada si no sabes cómo cobrarlo. Por eso voy a hacer una clase en vivo donde te enseño exactamente cómo vender este tipo de soluciones de AI a empresarios y a empresas. Así que comenta clase y te mando el acceso.
